# Analysis

This directory contains the computational-analysis materials for the study.

The model compares:
- A — freshwater baseline
- B — hybrid seawater-assisted cooling
- C — offshore submerged cooling

Planned reproducible analyses:
1. Baseline multi-criteria score
2. Priority-weight stress test
3. Hybrid/offshore break-even analysis
4. One-at-a-time input perturbation

**Data discipline:** modeled inputs must remain distinguishable from measured observations. Empirical values must include source, date, unit, context, and transformation method.
